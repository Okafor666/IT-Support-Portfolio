# Zapier Automation Project

## Project Overview

This project demonstrates my practical experience using Zapier to automate business and customer support workflows.

The automation was designed to connect different applications, reduce repetitive manual tasks, improve workflow efficiency, and ensure that important customer information is transferred accurately between platforms.

## Project: Freshdesk Ticket to Trello Card Automation

I created a Zapier automation that connects Freshdesk with Trello.

The workflow automatically creates a Trello card when a new customer support ticket is received in Freshdesk.

### Workflow

**Freshdesk → Zapier → Trello**

1. A new support ticket is created in Freshdesk.
2. Zapier detects the new ticket.
3. Relevant ticket information is captured.
4. Zapier transfers the information to Trello.
5. A new Trello card is automatically created.
6. The Trello card contains important ticket details such as the customer name, issue, priority, ticket number, and other relevant information.
